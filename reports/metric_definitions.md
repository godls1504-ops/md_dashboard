# 상품 운영 진단 지표 정의서 (초안)

- **목적**: 시즌 중간 상품 운영 성과·재고 건전성 진단 지표의 계산 기준 확정 (계산 코드 착수 전 합의용)
- **근거**: 데이터셋 README 정의, [table_selection.md](table_selection.md), CLAUDE.md 「분석 결정 사항(확정)」
- **통제**: 부분취소·쿠폰 배부·완료 반품·비용 범위는 **임의로 정하지 않고** 6절 「사용자 결정 필요」로 분리. 승인 전 계산 코드 미작성.
- **공통 확정 전제**
  - 분석 기준일 = **2026-07-31** (재고 스냅샷 존재 확인: 7/5·12·19·26·**31**)
  - 기준일 이후 이벤트 9건(취소 2·반품 7)은 **미발생** 처리
  - 전사·채널 매출/이익은 **주문(order_id) 단위**, 상품·카테고리·SKU 성과는 **order_item 단위**
  - 발주 6~7월 0건은 결측이 아니라 **발주 중단**

> 아래 계산식의 `[D#]`는 6절 결정 항목과 연동된다. 결정 전까지는 해당 지표를 **확정값으로 산출하지 않는다.**

| 업무 질문 | 취소를 제외하고 실제로 팔린 수량은? |
| 계산식 | Σ ( `수량` − `canceled_qty` ) · 기준일 이후 취소(2건)는 미취소로 보아 차감 안 함 `[D1]` |
| 분석 단위 | SKU → 상품 → 카테고리 (order_item 집계) |
| 기준일 | 2026-07-31 |
| 집계 기간 | 시즌 누적 2026-02-01 ~ 기준일 (주문일시 기준) |
| 포함·제외 | 유효 주문상태만 포함; 기준일 이후 주문 제외; 기준일 이후 취소 미반영 |
| 분모 0 처리 | 해당 없음(합계 지표) |
| 원천 테이블·열 | `order_item`(수량, canceled_qty, cancel_date, order_item_status), `orders`(주문일시) |

| 해석 제한 | 부분취소 반영 방식(`[D1]`)에 따라 값이 달라짐 |

| 필드 | 내용 |

| 업무 질문 | 취소·완료반품까지 뺀 실판매 수량은? |
| 계산식 | 유효판매수량 − Σ(완료 반품수량) `[D3]` |
| 분석 단위 | SKU → 상품 → 카테고리 |
| 기준일 | 2026-07-31 |

| 포함·제외 | 완료 반품만 차감(처리상태='완료' & 처리일 ≤ 기준일); 진행 중·기준일 이후 처리(7건) 제외 |
| 분모 0 처리 | 해당 없음 |
| 원천 테이블·열 | 1번 + `returns`(반품수량, 처리상태, 처리일, order_item_id) |
| 검증식 | 순판매수량 ≤ 유효판매수량; 완료 반품수량 ≤ 유효판매수량 |
| 해석 제한 | 반품 시점 처리(`[D5]`) 영향; 재고주수 분모로 사용 |

## 3. 순매출

| 필드 | 내용 |
|---|---|
| 업무 질문 | 실제로 남은 매출액은? |
| 계산식 | Σ[ `판매단가` × (수량 − canceled_qty) − 쿠폰할인액(유효수량 배부) ] − 완료 반품 `환불금액` `[D1][D2][D3]` |
| 분석 단위 | 상품 성과=SKU→상품→카테고리; 전사·채널=주문(order_id) 집계 |
| 기준일 | 2026-07-31 |
| 집계 기간 | 시즌 누적 2026-02-01 ~ 기준일 |
| 포함·제외 | 쿠폰할인액 차감; `배송비배부액`은 매출 아님(비용측); 상품할인액 중복차감 금지 `[D7]` |
| 분모 0 처리 | 해당 없음 |
| 원천 테이블·열 | `order_item`(판매단가, 수량, canceled_qty, 쿠폰할인액, 상품할인액, 정상가), `returns`(환불금액, 처리상태, 처리일) |
| 검증식 | 순매출 ≤ Σ(판매단가×수량); `정상가 − 상품할인액 =? 판매단가` 확인(중복차감 방지) `[D7]` |
| 해석 제한 | 판매단가=현재가 vs 주문시점가 혼입 가능; 쿠폰 코드-금액 불일치(803/1,350건)로 **코드 기준 추적 불가**, 금액 기준만 신뢰 |

## 4. 가용 공헌이익

| 필드 | 내용 |
|---|---|
| 업무 질문 | 이 상품이 실제로 남기는 돈은? |
| 계산식 | 순매출 − ( 원가 + `채널수수료액` + `payment_fee_amount` + `fulfillment_cost_amount` + `packaging_cost_amount` + 완료반품 처리비 ) `[D4]` |
| 분석 단위 | SKU → 상품 → 카테고리 |
| 기준일 | 2026-07-31 |
| 집계 기간 | 시즌 누적 |
| 포함·제외 | 비용 6종(`[D4]`); 원가 = 기준원가 vs 실매입 단위원가(`[D4]`); 반품처리비=완료 반품만; **광고비는 상품 귀속 불가로 제외** |
| 분모 0 처리 | 마진율 산출 시 순매출=0 → 정의 불가(null) |
| 원천 테이블·열 | `order_item`(비용 4열, 수량, canceled_qty), `product_master`(기준원가) 또는 `purchase_order`(단위원가), `returns`(return_handling_cost, return_shipping_cost) |
| 검증식 | 가용 공헌이익 ≤ 순매출; 각 비용 ≥ 0 |
| 해석 제한 | 원가 기준 선택(`[D4]`)에 민감; 마케팅비 제외한 **상품 자체 마진** |

| 분석 단위 | SKU → 상품 → 카테고리 |

| 집계 기간 | 시즌 누적 |

| 분모 0 처리 | 유효판매수량=0 → 정의 불가(null, '판매 없음' 표시, 비율 미산출) |

| 해석 제한 | 주간 스냅샷이라 기준일 정확 재고만 사용; 판매속도 변동 큰 SKU는 WOS 불안정 |

## 6. 사용자 결정 필요 (데이터로 확정 불가)

> 아래가 정해져야 위 `[D#]` 지표를 확정 산출한다. 각 항목에 기본 제안을 붙였으나 **임의 확정하지 않음.**

| ID | 결정 항목 | 쟁점 | 기본 제안(미확정) |
|---|---|---|---|
| **D1** | 부분취소 반영 | `canceled_qty`(부분 0·1·2) 차감 시 금액은 `canceled_amount` 그대로 쓸지, 수량 비례로 재배분할지 | 수량은 canceled_qty 차감, 금액은 canceled_amount 사용(불일치 시 검증 후 결정) |
| **D2** | 쿠폰 배부 | 부분취소 시 `쿠폰할인액`을 잔여 유효수량에 비례 배부(prorate)할지 | 유효수량 비례 배부 |
| **D3** | 완료 반품 정의 | 진행 중(접수·미처리 32건) 반품을 순매출·순판매·반품률에 포함할지 | 처리상태='완료' & 처리일 ≤ 기준일 **만** 반영 |
| **D4** | 공헌이익 비용 범위·원가 기준 | 비용 6종 확정 여부 + 원가를 `기준원가`(표준) vs `단위원가`(실매입) 중 무엇으로 | 비용 6종 포함, 원가=기준원가 |
| **D5** | 판매속도·순판매의 반품 반영 | 최근 28일 순판매에서 반품을 **판매일** 기준으로 뺄지, **반품일** 기준으로 뺄지(창 밖 반품 처리) | 판매일 기준 창 산정, 완료 반품만 차감 |
| **D6** | WOS 분모 0 표기 | 판매속도 0(무판매)일 때 WOS를 ∞/상한캡/null/플래그 중 무엇으로 | 수치 null + '무판매 과잉재고' 플래그 |
| **D7** | 판매단가-상품할인액 중복 | `판매단가`에 `상품할인액`이 이미 반영됐는지(중복 차감 방지) | 데이터 검증(`정상가−상품할인액=판매단가`) 후 결정, 기본은 중복 차감 안 함 |
| **D8** | season 매칭 규칙 | 상품 `시즌`(SS/상시) ↔ 정책 `season` 매칭 방법(불일치 시 대체) | category_id 우선 매칭, season 불일치 시 '상시' 정책 대체(미확정) |

**확정으로 처리한 통제 항목**: 재고 기준일 = 2026-07-31 (스냅샷 존재), 기준일 이후 9건 미발생, 집계 단위(전사=주문/상품=order_item), 8월 정책 포함, 발주 중단.

## 통제 준수
- 부분취소·쿠폰 배부·완료 반품·비용 범위는 임의 확정하지 않고 6절로 분리.
- 승인 전 계산 코드 미작성. 본 문서는 정의 합의용 초안이다.
